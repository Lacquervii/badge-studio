# 徽章工坊（Obsidian 徽章插件）设计文档

日期：2026-10-14
状态：已与用户确认（脑暴记录见对话）
目标库：Lacquervii（iCloud 同步库）
开发目录：/Users/farroadeta/Downloads/github标签

## 1. 背景与目标

用户希望在 Obsidian 笔记里放 GitHub README 那种盾牌徽章（两段式：左深灰块＋右彩色块；或单段彩色块）。核心诉求：**徽章不依赖插件存活**——插件关闭或卸载后，笔记里的徽章依旧正常显示。

由此确定的核心机制：插件把每个徽章画成一张 **SVG 小图片文件**存进库内素材文件夹；笔记里写的是 Obsidian **原生嵌图语法**（`![[...]]`），带链接时外包原生链接语法。原生语法由 Obsidian 自身渲染，与插件无关。

## 2. 核心决策记录（脑暴结论）

1. 主形态＝SVG 嵌图行（耐用）；不采用「正文标记行＋插件实时渲染」为主形态。
2. 编辑（实时预览）与阅读模式都显示徽章（嵌图为 Obsidian 原生行为，两模式自动满足）。
3. 设置里两层标签库：**样式层**（配色方案）＋**标签层**（徽章条目，引用样式）。
4. 侧边栏面板点选插入；命令面板打字模糊搜插入。
5. 附加功能：#标签 渲染成徽章皮肤（设置开关；实时渲染，卸插件失效，已告知用户）；徽章可选带链接（阅读模式点击跳转）。
6. 首次安装自带 GitHub 同款配色样式一套＋3 个示例标签。
7. 改标签定义→重画对应 SVG→全库引用处一起更新；删条目不删 SVG 文件（防引用变空）。

## 3. 数据模型（data.json）

```jsonc
{
  "assetsFolder": "徽章素材",        // 库内文件夹名，可改
  "renderTags": true,               // #标签 皮肤总开关
  "defaultStyleId": "s001",         // 默认样式（#标签 未匹配时、临时徽章未选时）
  "styles": [
    { "id": "s001", "name": "黄", "leftBg": "#555555", "rightBg": "#ffd400" }
  ],
  "badges": [
    {
      "id": "001",                  // 稳定编号，同时决定文件名 badge-001.svg
      "name": "状态-进行中",         // 用于侧边栏/搜索显示
      "leftText": "状态",            // 留空＝单段徽章
      "rightText": "进行中",
      "styleId": "s001",
      "tag": "",                    // 选填：对应 #标签 名（不含 #）
      "link": ""                    // 选填：网址 或 库内笔记名
    }
  ]
}
```

- 样式字段仅：名字、左块颜色、右块颜色。文字颜色按底色亮度自动黑/白（YIQ≥128 黑，否则白），不开放设置。
- 圆角固定 4px、高度固定 20px（shields 规格），不开放设置。

## 4. SVG 生成规则

- 文件：`<assetsFolder>/badge-<id>.svg`，单文件 1~2KB。
- 两段式：左矩形 leftBg＋左文字；右矩形 rightBg＋右文字；单段式：单矩形 rightBg＋文字。
- 宽度计算：生成时用 canvas `measureText` 按字体栈 `Verdana, Geneva, PingFang SC, Microsoft YaHei, sans-serif`、11px、bold 实测文字宽度；左右内边距各 7px。SVG 内 `<text>` 同时写 `textLength`＝实测宽度（`lengthAdjust="spacingAndGlyphs"`），保证任何环境下不溢出不留空。
- 根元素写 width/height（px）与同值 viewBox，矢量清晰、随缩放不糊。
- 触发重画：设置里新增/修改/删除标签或样式后，对受影响的徽章重画写盘；插件首次加载若 data.json 不存在则写入默认值并生成全部默认 SVG。

## 5. 插入与成排规则

- 插入内容：`![[<按用户链接设置生成的嵌图链接>]]`（用 `fileManager.generateMarkdownLink` 生成后加 `!` 前缀，兼容用户的链接格式设置）；带链接条目则外包 `[ ... ](<link>)`：link 以 http(s):// 开头＝外部网址原样用；否则按笔记名解析（`metadataCache.getFirstLinkpathDest`），解析到则用其文件链接；解析不到则原样当地址用（由用户自己负责）。
- 插入位置：当前光标处（行内插入）。同一行连续插入多个＝一排；行宽超出自动换行（图片行内联flow）；换行写＝新一排。
- 侧边栏「临时徽章」表单（左字、右字、样式下拉）：创建新条目（name 自动为「临时 n」）→生成 SVG→插入；事后可在设置里改名/改/删。

## 6. 侧边栏与命令

- 左侧 ribbon 增加图标（lucide `shield`），点击打开/聚焦右侧面板（ItemView，VIEW_TYPE `badge-studio-sidebar`）。
- 面板自上而下：搜索框；标签清单（每行＝徽章真实样子预览〔img + data:image/svg+xml〕＋名字）；「临时徽章」按钮（展开上述表单）；「打开设置」按钮。
- 点清单某行＝在最后一个活动的 Markdown 编辑器光标处插入。
- 命令面板命令「插入徽章：搜索并插入」：SuggestModal 按名字模糊搜，回车插入，同上。

## 7. 设置界面（PluginSettingTab）

- 顶部：开关「把 #标签 渲染成徽章」；下拉「默认样式」；文本框「素材文件夹名」。
- 样式层区块：列表（名字＋双色块预览＋编辑/删除）；「新建样式」展开表单（名字、左块颜色、右块颜色；颜色用取色器＋hex 输入）。
- 标签层区块：列表（真实样子预览＋名字＋编辑/删除）；「新建标签」展开表单（名字、左字、右字、样式下拉、对应 #tag、链接）。
- 删除条目：仅删数据，不删 SVG 文件。
- 默认内置样式：黄 #ffd400、绿 #4caf50、红 #e05d44、蓝 #007ec6、紫 #7c3aed、橙 #f97316、灰 #555555（leftBg 均 #555555）；示例标签 3 个（名字｜左字｜右字｜样式）：「状态-进行中」｜状态｜进行中｜黄、「科目-现代汉语」｜科目｜现代汉语｜蓝、「单段-示例」｜（空）｜示例｜紫。

## 8. #标签 皮肤（附加，实时渲染）

- 仅处理正文；代码块、行内代码、属性区里的 #标签 不动。
- 匹配：标签名（不含 #）== 某条目 `tag` 字段 → 按该条目样子渲染（可两段）；否则用默认样式渲染单段小徽章（文字＝标签名）。
- 阅读模式：MarkdownPostProcessor 内找 `a.tag` 元素替换为同规格 DOM 芯片。
- 编辑（实时预览）：CodeMirror ViewPlugin＋`Decoration.replace`（widget 为同规格 DOM 芯片）；正则 `/#[\p{L}\p{N}_\/-]+/u` 匹配，借助 syntaxTree 跳过代码/数学节点；光标落在标签范围内时该处不装饰（露出原文便于编辑）。
- 明确限制：此皮肤为实时渲染，插件关闭/卸载即失效（用户已知悉并接受）。

## 9. 边界与不做的事（YAGNI）

- 不做：未引用 SVG 的清理工具、重命名条目时改写全库引用、源代码模式渲染（Obsidian 限制）、移动端专门适配、徽章图标/logo 字段。
- 嵌图行被复制到 Obsidian 之外＝普通文本/失效图片，属预期（耐用性指「在 Obsidian 内不依赖本插件」）。
- iCloud 同步：插件与 SVG 都会同步到用户其他设备，属预期（已提醒）。

## 10. 交付与验收

- 开发：当前目录，TypeScript＋esbuild 编译出 main.js / manifest.json / styles.css。
- 安装：复制到 Lacquervii 库 `.obsidian/plugins/badge-studio/`，设置里启用。
- 验收清单（建一篇测试笔记逐项过目）：
  1. 侧边栏点插单段/两段徽章，编辑、阅读两模式显示正确；
  2. 同行连点成排、超宽换行、换行分排；
  3. 临时徽章表单造一个并插入；
  4. 命令面板搜索插入；
  5. 带链接徽章在阅读模式点击跳转（网址＋笔记各一）；
  6. 设置里改某标签文字/配色→所有引用处一起变；
  7. #标签 皮肤开/关对比；代码块内 #标签 不变；
  8. **关掉插件重开笔记：所有 SVG 徽章依旧显示、链接依旧可点**（核心要求）；
  9. 光标点到嵌图行露出原始语法、可编辑。
