# 宣传海报提示词（logo 融入版 · image 2.5）

> 这次的思路：**logo 是画面里的一个元素**（视觉焦点或品牌落款），由参考图提供；提示词负责背景、光效、构图和留白。

## 占位符约定

- `[LOGO]` = 你上传的那张 logo 参考图（`assets/logo/logo-512.png`）。
- 提示词里出现 `[LOGO]` 的位置，就是 logo 在画面里出现的位置和大小。
- 各平台写法不同，替换一下即可：即梦 / 豆包 → `图1`；Midjourney → `--cref` 配 `/1`；其它平台 → `reference image 1`、`@参考图1`。本文档统一用 `[LOGO]`。

## 用之前先记住三句

1. **上传 logo 后，AI 有可能把它"重绘"得变形**（比例走样、颜色跑偏、边框乱加）。挑片时优先看：logo 是否还是圆角方形、白蓝两段是否分明。提示词里已经写了"原样保留"，但一定要多抽几张挑。
2. **不要让 AI 写中文**。画面里所有"文字"都用模糊灰色短条代替，标题卖点后期压上去（文案在文末）。
3. **尺寸**：竖版 3:4（小红书 / 朋友圈）、16:9（PPT / 封面）、2.35:1（GitHub 横幅）。

## 方案 A · 焦点悬浮（推荐）

```
一张竖版宣传海报（3:4），深色科技风，极简高级。

参考图：[LOGO] 是一枚圆角方形应用图标（深色底板，上面一枚白色与天空蓝拼色的横向胶囊徽章，右上角一颗白色星光）。请原样保留它的形状、比例与配色，不要重绘、不要变形、不要缩放拉伸、不要在它上面加任何文字。

[LOGO] 悬浮在画面中央偏上，占画面宽度约 20%，图标下方有柔和的蓝色辉光与极淡的倒影，边缘干净完整、不被裁切。

从 [LOGO] 周围向四周扩散漂浮着十几枚小徽章（横向胶囊形、左右两段拼色），颜色有明黄、翠绿、紫罗兰、珊瑚橙、青碧，由近及远逐渐变小、变虚，带浅景深和柔和光晕。

背景：深蓝黑竖向渐变（顶部 #22303f 到底部 #141d27），铺一层极淡的等距网格线，背景中有微弱蓝色辉光和漂浮的细小微粒。

构图：画面顶部三分之一完全留白用于排版标题，底部留出约五分之一空白。

不要出现：任何文字、字母、数字、水印、签名、二维码、人物。
```

## 方案 B · 徽章墙中心

```
一张竖版宣传海报（3:4），深色高级质感。

参考图：[LOGO] 是一枚圆角方形应用图标（深色底板 + 白色与天空蓝拼色的胶囊徽章 + 右上角白色星光）。原样保留，不要重绘、不要变形、不要加字。

背景：深蓝黑竖向渐变（#22303f 到 #141d27），铺着整齐的等距网格。

画面中下部是一面徽章墙：几十枚横向胶囊形徽章按网格整齐排列（明黄、翠绿、紫罗兰、天空蓝、珊瑚橙、青碧），每枚由左右两段拼成，带轻微立体投影，像一块精致的图标矩阵。

[LOGO] 位于徽章墙正中偏上，明显更大、被点亮，带一圈柔和的蓝色光晕；周围的小徽章向它微微倾斜，形成聚焦感。徽章墙向画面下方逐渐变暗淡出。

画面顶部三分之一保持完全干净的留白。

不要出现：任何文字、字母、数字、水印、二维码、人物。
```

## 方案 C · 笔记面板 + 品牌角标

```

参考图：[LOGO] 是一枚圆角方形应用图标（深色底板 + 白色与天空蓝拼色的胶囊徽章 + 右上角白色星光）。原样保留，不要重绘、不要变形、不要加字。
```

## 如果你的平台不支持参考图（纯文字备用描述）

把上面每个提示词里的 `[LOGO]` 换成下面这段：

```
一枚圆角方形应用图标（圆角约为边长的 22%，底色是深蓝黑 #1a232e），底板正中央是一枚横向胶囊形徽章：左半为白色渐变，右半为明亮的天空蓝渐变（#5bc8ff 到 #0ea5e9），宽度约为底板的 72%；徽章的右上角有一颗白色四角星光。
```

## 后期压字的排版模板

位置：方案 A、B 放画面顶部三分之一；方案 C 放顶部；方案 D 放画面下方。

```
主标题（一行，字号＝画面宽度的 6%~8%）
    笔记里的进度，一眼看得见
副标题（主标题的 1/3 大小，灰色）
    给 Obsidian 笔记加一套 GitHub 风格的进度徽章
卖点小字（再小一号，用间隔点分开）
    两段配色 · 内置图标 · 点击跳转 · 一键固化成图片
底部小字
    GitHub 搜索 Badge Studio  |  <仓库链接>
```

字体：中文用苹方 / 思源黑体，英文用 Inter / SF Pro；只用白 + 一种灰两种文字颜色。

## 标语备选

- 笔记里的进度，一眼看得见
- 给每一条笔记，别上一枚徽章
- 状态 · 科目 · 难度，一枚徽章说清
- 不用再数标签，徽章替你说话
