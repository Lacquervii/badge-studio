## 长版（论坛帖 / README 开头）

**Badge Studio 徽章工坊 —— 给 Obsidian 笔记加上 GitHub 风格的徽章**

笔记里最缺的往往不是内容，而是"一眼就知道这条笔记到哪一步了"。

Badge Studio 让你在自己的笔记里插入 GitHub 风格的盾牌徽章：

```
状态 | 进行中      科目 | 现代汉语      实践 | 已完成
```

**它能做什么**

- **两段式配色**：左块写分类、右块写状态；每枚徽章的颜色由自己保存，样式库提供一键套用的配色模板（改样式、删样式都不会动到已有徽章）
- **侧栏工坊**：搜索徽章、点一下就插到光标处，也可以直接拖进笔记；每枚徽章都显示被多少篇笔记引用
- **图标**：可给徽章配图标 —— 内置 1000+ 个（填个名字就行），也能粘贴自己的 SVG，颜色自动跟随徽章配色
- **可点击**：徽章能挂链接，点击直接跳到对应笔记或外部网址
- **可固化**：一键把笔记里的徽章"焊"成真正的 SVG 图片 —— 之后换设备、发给别人、甚至卸载这个插件，徽章都还在

**为什么做这个**

起因很简单：备考笔记里需要"一眼看清每条的进度"，又不想把徽章托管在别人的服务器上 —— 那些在线徽章服务一断，笔记里就只剩一串红叉。所以做了这个完全跑在本地的版本。

**怎么获取**

把插件文件夹放进 `你的库/.obsidian/plugins/badge-studio/`，在 Obsidian 设置里启用即可。
