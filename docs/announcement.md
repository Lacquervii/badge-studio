## 长版（论坛帖 / README 开头）

**Badge Studio 徽章工坊 —— 给 Obsidian 笔记加上 GitHub 风格的徽章**

笔记里最缺的往往不是内容，而是"一眼就知道这条笔记到哪一步了"。

Badge Studio 让你在自己的笔记里插入 GitHub 风格的盾牌徽章：

```
状态 | 进行中      科目 | 现代汉语      实践 | 已完成
```

**它能做什么**

- **两段式配色**：左块写分类、右块写状态；每枚徽章的颜色由自己保存，样式库提供一键套用的配色模板（改样式、删样式都不会动到已有徽章）
- **侧栏工坊**：搜索徽章、点一下就插到光标处，也可以直接拖进笔记；每枚徽章都显示被多少篇笔记引用
- **图标**：可给徽章配图标 —— 内置 1000+ 个（填个名字就行），也能粘贴自己的 SVG，颜色自动跟随徽章配色
- **可点击**：徽章能挂链接，点击直接跳到对应笔记或外部网址
- **可固化**：一键把笔记里的徽章"焊"成真正的 SVG 图片 —— 之后换设备、发给别人、甚至卸载这个插件，徽章都还在

**为什么做这个**

起因很简单：备考笔记里需要"一眼看清每条的进度"，又不想把徽章托管在别人的服务器上 —— 那些在线徽章服务一断，笔记里就只剩一串红叉。所以做了这个完全跑在本地的版本。

**怎么获取**

把插件文件夹放进 `你的库/.obsidian/plugins/badge-studio/`，在 Obsidian 设置里启用即可。

## 完整介绍（分节版 · 适合单独发一帖）

> 下面整段可以直接复制，分成四小节，读起来像一篇正经的插件介绍。

### 它是什么

**Badge Studio 徽章工坊**是 Obsidian 的一款插件，让你在笔记里插入 GitHub 风格的盾牌徽章：左边写分类，右边写状态，颜色自己定。

```
状态 | 进行中      科目 | 现代汉语      进度 | 60%
```

扫一眼笔记，哪条在推进、哪条卡着、哪条已经收尾，一目了然。

### 解决什么问题

备考、写论文、做项目，笔记越攒越多，光看标题根本想不起来进度。标签只能分类，写不出"现在到哪一步"。

徽章补的就是这个空：它是一段**带颜色和状态的视觉标记**，比文字标签直观得多 —— 不用点开笔记，也不用翻看内容，状态写在脸上。

### 怎么用

1. 侧栏「徽章工坊」里新建徽章：起名字、写左右文字、选配色、加图标
2. 点一下就插到笔记里，或者直接写一行 `badge: 名字`
3. 编辑模式和阅读模式都会把它渲染成徽章；想把徽章彻底变成本地图，运行「固化本篇徽章为图片」

### 几个亮点

- **徽章自带颜色**：不受样式库增删影响，改样式、删样式都动不到已有徽章
- **图标**：内置 1000+ 个，填个名字就行；两个胶囊的左右两侧各能放一枚，也能粘贴自己的 SVG
- **可点击**：徽章能挂链接，点了直接跳到对应笔记或外部网址
- **可固化**：变成真正的 SVG 图片 —— 换设备、发给别人、甚至卸载插件，徽章都还在
- **侧栏两种视图**：列表（带名字和引用数）/ 堆放（纯徽章流），支持搜索和拖拽插入

### 适合谁

备考的人、写论文的人、做项目笔记的人，以及任何需要在大量笔记里快速分辨状态的人。
